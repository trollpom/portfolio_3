# Анна и Михаил — свадебное приглашение

Демонстрационное веб-приложение: история пары, программа, галерея, дресс-код, FAQ, календарь и форма RSVP. Персонажи, дата и площадка вымышлены; изображения созданы ИИ.

**Статус:** проект для портфолио. Автор — [Евгений Смирнов](https://github.com/trollpom), разработка с помощью ИИ и AI coding tools. Коммерческий заказ и реальные гости не заявляются.

## Технологии

TypeScript · React · Next.js · Tailwind CSS. Серверный адаптер Netlify Blobs сохранён для отдельно настроенного хостинга.

## Запуск и проверки

Нужны Node.js 24 и pnpm 11.25.0 из `packageManager`.

```bash
git clone https://github.com/trollpom/portfolio_3.git
cd portfolio_3
pnpm install
pnpm dev
pnpm test
pnpm build
pnpm start
```

Локальный Next.js показывает интерфейс. Для сохранения RSVP требуется настроенный серверный контекст Netlify; без него API возвращает 503. Настройки сборки находятся в `netlify.toml`: команда `pnpm run build`, папка публикации `.next`. Это серверное приложение, поэтому загрузка исходников как обычных статических файлов не заменяет сборку.

## Текущая Vercel-демоверсия

https://portfolio-3-mauve-three.vercel.app/

29.10.2026: production-деплой `READY`, главная страница HTTP 200. Корректный синтетический POST `/api/rsvp` вернул HTTP 503: адаптер ожидает Netlify Blobs, а на Vercel нет его серверного контекста. Сохранение реальных RSVP не заявляется.

Интерфейс определяет наличие серверного хранилища при рендеринге. Если оно не подключено, кнопка отправки отключена и показано пояснение деморежима. Введённые сведения не отправляются. Состояние не подменяется браузерным `localStorage` или временной памятью сервера.

Минимальный рабочий вариант в будущем — отдельно согласовать серверное хранилище и адаптер для Vercel либо использовать текущий адаптер на Netlify. Новое хранилище, платные услуги и сбор персональных данных в рамках этой доработки не подключались.

## Как показать проект

Открыть страницу на телефоне и компьютере, проверить меню и галерею с клавиатуры, скачать календарь, отправить вымышленный RSVP в настроенной тестовой установке. Без серверного хранилища форма остаётся демонстрационной: элементы можно изучить, отправка отключена.

## Устройство

`app/wedding.tsx` и `app/globals.css` — интерфейс; `app/api/rsvp/route.ts` — API; `lib/rsvp-service.ts` — проверка данных; `tests/rsvp.test.ts` — тесты контракта с тестовым хранилищем; `public/` — локальные изображения, шрифты и календарь.

Тесты не подтверждают доступность конкретного опубликованного сайта. В проекте сохранены материалы предыдущего режима сборки; для текущего Netlify используется Next.js.
